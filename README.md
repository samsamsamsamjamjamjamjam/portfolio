# Law School Teaching Portfolio

This repository hosts the academic teaching portfolio for **Kayla Howsare**, a 2L law student.

## Purpose
This site serves as an interactive hub for my Teaching Assistant applications. It demonstrates my approach to legal pedagogy: **Innovative, United, and Encouraging.**

Each section represents a targeted roadmap for specific courses, bridging the gap between dense doctrinal theory and real-world transactional/litigation practice.
